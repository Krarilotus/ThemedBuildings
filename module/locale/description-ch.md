# Themed Buildings

**作者**：Monsterfish
**版本**：1.0.2

让礼拜堂、教堂和大教堂采用所属领主的建筑风格。欧洲领主建造礼拜堂、教堂和大教堂；阿拉伯领主建造小清真寺、清真寺和大清真寺。若游戏的 `tile_churches.gm1` 包含废墟贴图（原版包含，Reconquista 不包含），被毁的大教堂也会显示为被毁的大清真寺。

每种建筑有两套贴图：游戏原文件贴图与本模块提供的主题贴图。你可以在设置中指定游戏原文件贴图属于哪一方（默认如 Reconquista，礼拜堂和大教堂为欧洲风格，教堂为清真寺），另一方的玩家将自动使用主题贴图。

领主阵营直接取自游戏本身：AI 领主保持各自阵营（包括 aiSwapper 的自定义 AI），玩家则随所选领主而定。不会向地图或存档写入任何数据。

需要 gmResourceModifier。
