# Themed Buildings

**Auteur** : Monsterfish
**Version** : 1.0.2

Les chapelles, églises et cathédrales adoptent l'apparence du seigneur qui les possède. Les seigneurs européens bâtissent une chapelle, une église et une cathédrale ; les seigneurs arabes bâtissent une petite mosquée, une mosquée et une grande mosquée. Une cathédrale en ruine devient une grande mosquée en ruine si le fichier `tile_churches.gm1` du jeu contient la ruine (présente dans le jeu d'origine, absente dans Reconquista).

Chaque bâtiment dispose de deux visuels : celui des fichiers du jeu et un visuel thématique fourni par ce module. Dans les paramètres, vous indiquez à quel camp appartient le visuel du jeu (par défaut la chapelle et la cathédrale sont européennes et l'église est une mosquée, comme dans Reconquista). Chaque joueur de l'autre camp reçoit le visuel thématique.

Le camp du seigneur provient du jeu lui-même : les seigneurs IA conservent le leur (y compris les IA personnalisées d'aiSwapper) et vous avez celui du seigneur que vous jouez. Rien n'est enregistré dans les cartes ni les sauvegardes.

Nécessite gmResourceModifier.
